# Rolling Updates And Availability

This module develops rolling Updates And Availability. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Identify changes that create Deployment revisions.
- Calculate surge and unavailability limits.
- Explain readiness and capacity effects on rollout.
- Distinguish reported progress failure from automatic recovery.
- Distinguish configuration as code from infrastructure provisioning and ongoing reconciliation.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
