# Configuration as Code (CaC)

This section covers configuration as Code (CaC). It develops rolling Updates And Availability through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Identify changes that create Deployment revisions.
- Calculate surge and unavailability limits.
- Explain readiness and capacity effects on rollout.
- Distinguish reported progress failure from automatic recovery.
- Distinguish configuration as code from infrastructure provisioning and ongoing reconciliation.
