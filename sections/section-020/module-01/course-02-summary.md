# Summary

Infrastructure as code expresses infrastructure management through reviewable inputs and provider contracts. Plans and provider state can help identify existing resources and proposed changes. Destruction, imports and sensitive state need deliberate handling. IaC and GitOps overlap but are not synonyms: a one-time apply can be declarative and versioned while lacking independent pull and continuous reconciliation. Evaluate the actual control path rather than the tool label.
