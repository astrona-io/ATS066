# Infrastructure as Code (IaC)

This section covers infrastructure as Code (IaC). It develops infrastructure Declarations, Plans And External Resource Lifecycle through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish infrastructure as code from application configuration.
- Explain provider state, plan review and lifecycle risks.
- Assess how an infrastructure workflow maps to GitOps principles.
