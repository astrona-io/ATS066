# Build And Release Pipelines

This module develops build And Release Pipelines. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Trace source changes through build, checks and artifact publication.
- Explain what continuous integration checks.
- Distinguish continuous delivery from continuous deployment.
- Relate release identity to an immutable artifact.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
