# CI and CD

This section covers cI and CD. It develops build And Release Pipelines through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Trace source changes through build, checks and artifact publication.
- Explain what continuous integration checks.
- Distinguish continuous delivery from continuous deployment.
- Relate release identity to an immutable artifact.
