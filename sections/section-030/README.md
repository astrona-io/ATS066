# DevOps and DevSecOps

This section covers devOps and DevSecOps. It develops shared Ownership, Feedback And Platform Enablement through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain DevOps and DevSecOps as collaborative practices.
- Distinguish platform enablement from transferring every responsibility.
- Reason about feedback, security and supported service boundaries.
